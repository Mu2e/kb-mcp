# Web Interface

The web interface provides a browser-based UI for managing and testing the knowledge base.

## Features

- **Document Management** - Add, view, search, and delete documents
- **Search & Testing** - Test semantic search with different parameters
- **Evaluation Dashboard** - Run and view evaluation experiments
- **Admin API** - Manage MCP API keys and server configuration

See [Admin API documentation](admin-api.md) for API key management details.

## Running the Web Server

```bash
# Start the web server
kb-server
```

The web interface will be available at the configured BASE_URL (default: https://127.0.0.1:8443).
